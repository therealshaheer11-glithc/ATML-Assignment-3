# Sources and reused code

- **VQA answer normalization:** `third_party/official_normalizer_reference.py` and `results/source/vqa_normalization.py` materially reuse the normalization methods from [GT-Vision-Lab/VQA](https://github.com/GT-Vision-Lab/VQA), `PythonEvaluationTools/vqaEvaluation/vqaEval.py`, credited upstream to `aagrawal`. The full retrieved source is preserved in `third_party/vqaEval_upstream_reference.txt`, and the source URL and SHA-256 records are in `results/source/normalizer_provenance/`. The project wrapper exposes `normalize_answer`; consensus scoring implements the assignment's explicit ten-reference formula. The preserved upstream `results/source/normalizer_provenance/external/vqaEval_upstream.py` is Python 2 source evidence, not an executable Python 3 entry point. Retained upstream text and notices are not relicensed by this package.
- **COCO 2014:** [COCO dataset](https://cocodataset.org/). Only frozen experimental selections, selected text references, derived annotation pools and source receipts are distributed here. Full annotation archives and original image files are external. Follow COCO and original image licensing terms.
- **VQAv2:** [Visual Question Answering](https://visualqa.org/). Frozen complementary-pair/question IDs and the selected ten human references are retained for reproducible subset scoring. This package does not redistribute the full raw dataset.
- **Qwen:** [Qwen/Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B). Revision `c1899de289a04d12100db370d81485cdf75e47ca`. Original pretrained weights are external and frozen in this experiment.
- **SigLIP:** [google/siglip-base-patch16-224](https://huggingface.co/google/siglip-base-patch16-224). Revision `7fd15f0689c79d79e38b1c2e2e2370a7bf2761ed`. Original pretrained weights are external and frozen.
- **Libraries:** PyTorch, Hugging Face Transformers, PEFT, Accelerate, safetensors, NumPy, Matplotlib and Pillow provide the model, numerical and plotting APIs. Original installed versions are retained in `environment/` and the run recipes. The project implementation uses these APIs rather than copying their implementations.
- **Coding assistance:** LLM assistance was used in implementation, debugging, auditing and packaging. This does not replace the author's responsibility for the code and results.

No new blanket software license is asserted here. Original third-party licenses and dataset/model terms continue to apply.
